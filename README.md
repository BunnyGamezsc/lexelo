## Purpose
Lexelo was created to provide a easier language learning and flashcard tool than other companies (like Quizlet)

(This project is in progress for the first release)

## Problems
1. Flashcard learners such as Quizlet lock learning and strengthening features behind a **paywall**
2. There is no **Grammar learning** feature for many languages in any other service

## Contributing
Lexelo Desktop is written with NextJS (Javascript) and Tauri (Rust).
### Step 1: [Download Npm and NodeJS](https://nodejs.org/) & [Download Pnpm](https://pnpm.io/)

### Step 2:
```bash
  git clone https://github.com/BunnyGamezsc/lexelo.git
  cd lexelo
  pnpm install
```

## Run/Build

### 1a. Run Desktop App Dev Server
```bash
  pnpm --filter desktop dev
```
### 1b. Run Desktop App
```bash
  pnpm --filter desktop app
```
### 2. Run Web App Dev Server
```bash
  pnpm --filter web dev
```
